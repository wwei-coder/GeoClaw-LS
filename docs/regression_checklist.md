# GeoClaw-LS 回归检查清单

## 目的

用于每次结构调整后的最小手动回归，重点覆盖 WebUI 主链路与关键 API。

## 手动验证项

1. 启动 WebUI
   - 执行 `python app.py`，确认控制台输出可访问地址，首页可打开。

2. 健康检查接口
   - 访问 `GET /api/health`，确认返回项目路径、配置路径和 Agent 导入状态。

3. 会话管理
   - 新建会话、切换会话、删除会话，确认前端列表与后端状态一致。

4. 普通知识库问答
   - 提问一个知识库内问题，确认有回答并附来源字段（sources）。

5. 文件上传
   - 上传 `csv/xlsx/xls/txt/json` 任一文件，确认上传成功并可在文件列表显示。

6. DATA_PROFILE 与产物下载
   - 对已上传文件触发数据分析，确认返回产物并可通过 `/api/artifacts/{artifact_id}` 下载。

7. 任务工作台
   - 发起一次带工具步骤的问题，确认任务列表、步骤状态、执行轨迹可查看。

8. 配置保存/导入/导出
   - 修改配置后保存，再执行导出、导入，确认配置项生效且未破坏运行。

9. 知识库状态/同步/重建按钮
   - 检查状态页可读，执行同步可完成；重建按钮流程可触发（仅验证流程，不强制全量重建）。

10. Phoenix 开关
    - 切换观测开关，确认状态变化可见且不影响主问答流程。

## 自动测试命令

```bash
python -m pytest
```
